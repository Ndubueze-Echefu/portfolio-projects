# Tic-Tac-Toe (Assembly Edition)



Have a blast with this game I made in assembly!



Two files:

* the .exe file to simply run.
* The .asm file for how it works.



If you want to learn more about the code; you can modify it using this free IDE I used for this program:

[Flat Assembler](https://flatassembler.net/)



Notes: 

* This only works on Windows machines. 🪟
* Antivirus will go to war with this executable due to it not being officially signed. You will have to disable it for a bit to run it. If that's too scary, you can always just inspect and assemble the code yourself.
